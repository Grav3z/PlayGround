## LAST RUN: BLACKOUT

A complete browser runner built with a self-contained HTML canvas—no install or external assets required. Open `index.html` in a browser, or serve this folder locally:

```sh
python3 -m http.server 3002
```

Then visit `http://localhost:3002`. Reach the extraction at 1,600 m with two lives. Change lanes with **A/D** or **←/→**, jump with **W/Space/↑**, slide with **S/↓**, and trigger the **Blackout pulse** with **E/X**. The pulse briefly slows hazards and disables nearby drones; avoid five hazards in a row to speed its recharge. Touch controls and swipe lane changes are also supported.
